### 🎓 Capstone Project

**Pacific Bonsai Museum — Digital Asset Management Redesign**
*Software Consultant Capstone · Dec 2025 – Present*

🔗 [Live Demo — Smart Image Uploader](https://team-bloom-capstone-image-uploader-1.onrender.com)

The museum's SharePoint system made it difficult for staff to search and organize their image library. As **lead developer** on a five-person team, I built an upload and tagging interface that wraps a computer vision pipeline around the museum's existing tools — no migration or new platform for staff to learn.

- Integrated **Azure AI** to batch-generate alt text and enable **text-to-image vector search** in SharePoint
- Designed configurable metadata fields that non-technical curators apply to photos **without training**
- Led regular client check-ins, translating curator workflows into actionable dev specs
- Iterated on tagging logic through **multiple redesigns** based on direct staff feedback

**Takeaways**
- Non-technical end users prioritize **consistency** over state-of-the-art model performance
- Real-world data curation took more effort than model tuning — and one model was abandoned entirely
- Most "engineering" on a client project is **translation** between what's requested, what's needed, and what's shippable

**Tech:** `PyTorch` · `YOLOv8` · `Azure` · `SharePoint` · `Power Automate`
